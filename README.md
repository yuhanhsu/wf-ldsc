# wf-ldsc

## Files for running S-LDSC analysis workflows on Terra
- *Dockerfile*: containerize ldsc scripts and dependencies
- *cloudbuild.yaml*: build and push docker image to Google Artifact Registry via Cloud Build
- *ldsc-l2.wdl*: define workflow to make annotation and compute LD scores for a given gene set
- *ldsc-h2.wdl*: define worklofw to partition heritability for a given trait x gene set
- *.dockstore.yml*: sync workflows to Dockstore for import to Terra
- *data/*: miscellaneous ldsc input files, generated by scripts in *data-scripts/*
